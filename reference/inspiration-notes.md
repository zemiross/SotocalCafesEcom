# Inspiration notes (brief §4)

The client supplied two reference videos; these notes record what the theme takes from them and what it leaves out.

## Reference A ("POUR / PLAY")
- Warm cream canvas; giant display type sandwiched in depth (background → type → photoreal object → particles); one material continues through every section; product cards orbit a ceramic cup at the end.

## Reference B
- A single coffee stream pours from the top edge onto an object that morphs (ice cube → glass → takeaway cup); object left, serif headline, copy and CTA right.

## Taken
| Idea | Where in the theme |
|---|---|
| Type in depth with an object | Hero: H1 behind the machine cut-out (line 2 split around it, D26); fold 5: headline partly behind the cup |
| One continuous material | The stream: one segment per fold, leading edge at 62% of the viewport, lit per fold theme |
| Scroll-driven transformation | Fold 2 beans roast (green → roasted at 0.55); fold 3 blend switching; fold 5 cup fills |
| Object on one side, text on the other | Folds 2–4: content in columns 1–5 and 8–12, the stream on the spine between them |
| Restraint | Nothing else moves; no section fade-ups; one accent CTA per fold |

## Left out
- Retro or groovy display fonts (DM Serif Display + Inter are locked).
- The product-card orbit collage (fold 3 shows one blend at a time instead, Hick).
- Live photoreal liquid morphs: the stream is CSS/SVG, the cup a live SVG, cut-outs are stills; the hero and fold 2 can take a scroll-scrubbed image sequence later (section settings).
- Foreground particles (would add motion outside the allowed list in §5.5).
